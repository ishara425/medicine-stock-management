# Medicine Management System

A full-stack application for managing medical stock, users, officers, distributions, restock requests, and notifications. This system is designed for organizations that need to track medicine inventory efficiently.

---

## 🚀 Tech Stack

### **Frontend**

* React (Vite)
* Axios
* Tailwind CSS (optional)

### **Backend**

* Node.js + Express
* Sequelize ORM
* MySQL Database
* JWT Authentication
* CORS Enabled
* Dotenv for environment configurations

---

## 📦 Features

* User Registration & Login (JWT based)
* Medicine CRUD operations
* Stock Management
* Officer Inventory Tracking
* Distribution Module
* Restock Request Handling
* Auto-generated Notifications
* Search, Filter & Sorting
* Role-based Authorization (Admin / Officer)

## 🛠️ Deployments

### **Azure Backend Deployment**

* Deploy via Azure App Service

### **Azure Frontend Deployment**

* Use Azure Static Web Apps
